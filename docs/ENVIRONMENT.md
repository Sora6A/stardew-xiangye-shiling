P1 已从规则核心推进至单人游戏原型。[保存与获取验证](validation/P1-persistence-2026-09-28.md) 使用真实游戏原生方法与磁盘存档；没有把数据检查或 JSON 克隆当作实际购买/保存。[Interaction 验证](validation/P1-ui-2026-09-30.md) 由实际界面输入执行获料/学习、制作、加工、烹饪、食用与皮埃尔售出。夹具直接打开 ShopMenu/CraftingPage，并准备资金、材料、设备放置、玩家定位和时钟，不覆盖 NPC 营业日程、步行开店、房屋厨房地图触发、手工放置、赠礼、工具击落拾取、手柄、英文或其他界面尺寸。P1 总体验收未完成，P2/P3 未开始，当前不是正式发行版本；完整状态以 validation 和 HANDOFF 为准。

UI 首轮历史失败保留：最后一步误选 Saloon，原生商店没有收购料理，15110g 和两份香椿拌豆腐未变化。按 [BUG-2026-008](bugfix/BUG-2026-008-ui-sale-shop.md) 修正售出目标为 SeedShop/皮埃尔，原生商店回归先红后绿，随后新一轮 13 步完整界面重跑通过，生产物品数据未改。最终售出两份各 240g，资金 15590g；背包余镐一把、豆腐一份、酱油四份，料理为零，购买原料全部消耗。食用恢复 175 能量和 78 生命。最终 UI 正常日志无 ERROR/WARN，与 Memory 两个预期故障 Error 分开统计。

三种夹具均默认禁用、不进入开发 ZIP。Memory 恢复内存且不保存；Persistence 会写指定独立副本；Interaction 不保存也不恢复本次内存，退出后须核对副本哈希。菜单成功一次后锁定，失败保留原请求供重试，契约和 BUG-2026-007 见 [P1 事务](P1_TRANSACTIONS.md)。

本轮 UI 测试游戏已退出，Get-Process 未发现 SMAPI；夹具已设置 Enabled=false、Scenario=Memory、OpenPreview=false。接手仍需重新核对进程和配置。
