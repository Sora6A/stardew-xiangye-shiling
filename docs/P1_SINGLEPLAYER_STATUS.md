# P1单人可玩版本状态

更新于 2026-11-16，Asia/Shanghai。本页记录玩家功能及其实机覆盖范围。P1 公共机制已通过，下一步扩充 P2 冻结内容。联机覆盖 Windows 原版环回直连。

11-12 同一次加载经实际地图步行、三店原版柜台采购、原版房门回家、制作放置、自然工时、领取及灶台烹饪和食用。夹具补建材及准备交互站位，采购原料和学习配方由本轮原版商店提供。最终余豆腐 1、酱油 4。见[同档实测](validation/P1-ordinary-play-2026-11-07.md#2026-11-12-同档从三店采购到加工食用)。

11-13 独立副本重走上述流程，随后使用原版床铺就寝，真实写盘后在另一进程冷重载。两设备仍是原实例和原状态，剩余库存及已学配方一致；重复原领取及空闲新领取均被拒绝。见[同档就寝与冷重载](validation/P1-ordinary-play-2026-11-07.md#2026-11-13-同档正常就寝与冷重载)。

11-16 在未升级的独立旧档从原版柜台实际购入设备建材和图纸，原版炉子冶炼，罗宾接单并完成三次原版就寝。用剩余建筑材料制作两台设备，并通过新灶台打开原版烹饪菜单。见 [建材和首次农舍升级](validation/P1-ordinary-play-2026-11-07.md#2026-11-16-原版建材和首次农舍升级)。

## 当前可用内容

当前激活7物品、5配方：黄豆、香椿、豆腐、酱油、香椿拌豆腐及两种设备。豆腐和酱油路线、原版厨房料理、三家商店原型来源都已有代码/数据实现。玩家操作见[上手指南](PLAYER_GUIDE.md)。

11-02至11-03本轮新增：机器菜单内两页获取/制作指南；缺料时列差额、变色与补料重试；成功反馈着色；五个现有物品的来源/使用提示。没有增加食品、种子、作物、配方或新持久化字段。
