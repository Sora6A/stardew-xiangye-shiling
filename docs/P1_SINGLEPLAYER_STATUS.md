# P1单人可玩版本状态

更新于 2026-11-11，Asia/Shanghai。本页记录玩家功能及其实机覆盖范围。P1 整体仍待验收，P2 冻结。联机写入继续禁用，NET02 高级矩阵单列。

11-11 在同一次游戏加载中完成原版购买、制作、放置、自然等待、灶台烹饪和食用。六笔交易共 4510g，最后余豆腐 1、酱油 4。夹具准备建材与站位并构造商店菜单，地图步行和店主日程单列。详见[无人值守实测](validation/P1-automated-route-2026-11-11.md)。

## 当前可用内容

当前激活7物品、5配方：黄豆、香椿、豆腐、酱油、香椿拌豆腐及两种设备。豆腐和酱油路线、原版厨房料理、三家商店原型来源都已有代码/数据实现。玩家操作见[上手指南](PLAYER_GUIDE.md)。

11-02至11-03本轮新增：机器菜单内两页获取/制作指南；缺料时列差额、变色与补料重试；成功反馈着色；五个现有物品的来源/使用提示。没有增加食品、种子、作物、配方或新持久化字段。

1. 在独立农场串联普通单人游玩。从农场步行到三家商店，按自然营业时间采购，制作和放置两台设备，等待游戏时钟走完加工，再领取、烹饪和使用成品。此前各子集和 11-07 当前 DLL 保存实测用于定位该链路的问题。
