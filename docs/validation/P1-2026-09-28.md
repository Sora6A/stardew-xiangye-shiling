## 实机集成场景

实际测试代码为 [GameHarness](../../tests/GameHarness/README.md)。最终 result.json：Passed 含下列 9 项，Failure=null，Restored=true。

| 场景 | 实际断言 |
|---|---|
| 商店与配方身份 | 黄豆限量库存存在；两设备/料理配方可解析，产出 ID 与内部 Name 正确，图纸/菜谱库存存在 |
| 缺第二种原料 | 发酵缸缺小麦时拒绝，黄豆原引用/数量与状态不变 |
| 跨品质与重放 | 按槽扣不同品质黄豆/小麦；固定品质明细；同请求再次执行不双扣 |
| 工作状态移除保护 | 工具、爆炸、NPC 清路、removeObject、destroyObject 均不移除 |
| 满包与整批领取 | 时钟前进至酱油完成；满包保持原状态，腾空后取得 4 份，再次请求不复制 |
| 损坏状态与空闲移除 | 非法 JSON 原值保留并锁住；新的空闲机器可正常 removeObject |
| 豆腐加工 | 真实扣除 3 黄豆，时间前进后领取 2 豆腐 |
| 库存回调抛异常 | OnSlotChanged 一次注入实际触发，操作拒绝，原引用/数量/JSON 恢复 |
| 库存回调静默改写 | 将新堆叠改为 99，写后核验发现不一致，拒绝且完整补偿 |

故障用例预期出现两个主模组 Error 日志：注入的 slot callback 异常和写集不匹配异常。最终无非预期用例失败；不能写成“日志零错误”。回滚失败隔离与日志回调异常覆盖在纯测试，未对真实存档注入不可恢复的破坏。
