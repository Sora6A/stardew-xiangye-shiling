日期：新档 2026-09-24，旧档副本 2026-09-25。范围为工程加载、独立黄豆记录和图标资源；不含生产玩法。

## 环境与来源

- Windows x64，OS build 10.0.26200；游戏 1.6.15 build 24356。
- SMAPI 4.4.0 来自[官方安装包](https://github.com/Pathoschild/SMAPI/releases/tag/4.4.0)。运行目录为工作区 `.local/validation-game`。
- Content Patcher 2.9.0 来自固定标签源码；提交 `807ca18be9291f301119a3fa01f49b6a59ac625f`。构建限制见[环境记录](../ENVIRONMENT.md)。
- 加载本项目 `0.1.0-alpha.1` 主模块与内容包。默认测试 Mods 中另有 SMAPI 自带 Console Commands、Save Backup。
- 主模块、CP 内容补丁均实际加载；`check-environment.ps1` 返回 `Issues: []`。
