# P1 无人值守单人链 · 2026-11-11

本轮使用当前开发包，在一次实际游戏加载中串联三店交易、制作与放置、两设备自然加工、烹饪和食用。环境为 Windows、Stardew Valley 1.6.15 build 24356、SMAPI 4.4.0、Content Patcher 2.9.0。

## 测试入口

从 `XYSP1Walk` 的磁盘快照复制独立 `XYSP1Route`。该专用副本起始有二级农舍厨房，未学模组配方，测试保留原资金 56,429,717g。夹具准备木材 80、石头 60、铜锭 1，并设置放置、开菜单和灶台所需站位。三家原版商店菜单由夹具构造，库存、扣款与配方学习走原版交易。设备使用原版配方、原版放置和生产菜单，等待期间只观察原版时钟。厨房使用地图灶台的实际 Action，等待原版冰箱锁返回后，在原版烹饪页制作。食用走原版角色方法。

场景由隔离后台进程运行，临时关闭失焦暂停并在退出前恢复。地图步行、NPC 自然营业、实体输入和食用确认框留给普通游玩验收。复跑配置见 [GameHarness 说明](../../tests/GameHarness/README.md)。

## 初次执行与修正

首次运行完成七项检查并取得豆腐 2、酱油 4。二级农舍的厨房在搬移后的地图区域，旧站位筛选还依赖装修矩形，找不到灶台。夹具改为读取原版厨房站位、实际 Action 格及碰撞，开工前预检厨房。随后的两次执行发现，接受灶台 Action 与出现烹饪页之间隔着原版冰箱锁。夹具改为在后续游戏帧等待烹饪页，并用原版退出入口释放冰箱锁。第四次执行走到烹饪，豆腐从 2 变为 1。原版菜单直接将成品放入背包，夹具原先只查看鼠标持有物。现改为核对实际背包和烹饪次数，只在原版菜单持有成品时点击空槽。各次失败均保留原报告，生产代码与存档未发生变化。

## 最终实测

同一游戏进程九项检查全部通过，`Completed=true`、`Failure=null`、`SavingObserved=false`。
