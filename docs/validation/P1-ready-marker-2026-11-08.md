# P1 地图成品提示 · 2026-11-08

豆坊和发酵缸加工完成后，在设备旁显示本批次的成品图标，领取成功后消失。提示由 [ReadyMachineMarker](../../src/XiangyeShiling/GameIntegration/ReadyMachineMarker.cs) 在原版地图对象绘制后追加。只读取当前地图设备的批次和原版时钟，领取仍走生产菜单事务。缺失或无法解析的状态、未知成品以及联机不显示提示；绘制不写入任何机器字段。

## 实机观察

Windows，游戏 1.6.15 build 24356、SMAPI 4.4.0、Content Patcher 2.9.0，中文窗口。隔离预览使用 `XYSP1Menu`，辅助模组仅在该专用档的内存准备一台待领取豆坊、一台加工中发酵缸、一台空闲豆坊，准备时将时刻置于 10:00，随后由原版时钟推进。三台设备前后相邻，原先悬高的标记容易被误认成后排设备。最终标记贴着设备格的右上侧，与对应互动区域一致。

| 检查 | 最终构建结果 |
| --- | --- |
| 同时有待领取、加工中和空闲设备 | 10:10 只在待领取豆坊旁看到豆腐图标。 |
| 豆坊领取 | 10:20 在标记处右键打开待领取设备，点击领取，背包增加豆腐 2，回到地图后提示消失。 |
| 发酵缸完成 | 11:20 仍无标记，原版时钟自然走到 12:00 时出现酱油图标。 |
| 发酵缸领取 | 12:20 在标记处右键，菜单领取酱油 4，回到地图后标记消失，背包保留两类成品。 |

首轮预览辅助模组误用泛型 API，未准备设备；已归档。修正后在独立进程验证，并用最终布局再完整核对以上四项。未覆盖户外地图、满包时的标记表现、坏状态和联机画面。此处的辅助准备及领取子集不代替[普通游玩](P1-ordinary-play-2026-11-07.md)。
