# P1 当前构建保存与冷启动实测 · 2026-11-07

当前生产构建在独立测试农场通过了豆坊和发酵缸的保存链。首个进程通过 Persistence 的全部六项检查，第二个进程从最终存档重新验证了重复领取拒绝。两次运行使用同一套游戏 1.6.15 build 24356、SMAPI 4.4.0、作者发行的 Content Patcher 2.9.0 和 `0.1.0-alpha.2` 模组。

源码基线为 `e3b2d575d21094750592531c9ee7dc6d100acff8`。运行前核对生产 DLL 和 GameHarness DLL 分别与本机 Release 输出一致，测试后再次核对部署哈希。生产 DLL 的 SHA-256 为 `47f32ff54ca3b861c323fde64319077eebeb038443a597cfc65484f6c4cb9e20`。

## 方法与结果

以尚未学习本模组配方的 P0 测试农场为源，按夹具说明创建新的 `XYSP1Save` 副本。夹具核对保存名、农场名和独立游戏 ID 后才执行，使用原版购买、制作、放置、保存和加载方法，机器动作经过生产 `MachineService`。测试材料、资金和阶段时钟由夹具准备。复跑方法见 [Persistence 模式](../../tests/GameHarness/README.md#persistence-模式会保存专用副本)。

| 检查 | 实际结果 |
| --- | --- |
| 原版购买、制作与放置 | 花费 4510g，余款 15490g，学会两张图纸与料理菜谱。制作消耗预备材料，空闲豆坊重新放置后取得新实例 ID。 |
| 两条配方路线 | 购买的材料经豆坊、发酵缸及原版烹饪，得到豆腐 1 份、香椿拌豆腐 1 份和酱油 4 份。 |
| 第一次标题重载 | 两台加工中、一台待领取、一台已领取。四台的状态原文和库存快照保持。待领取豆坊可领，已领取豆坊的旧请求被拒绝。 |
| 原生跨季保存与重载 | 原生日切换从春 28 到夏 1。重载后豆坊和发酵缸均可领取，保存矩阵库存累计豆腐 6 份、酱油 4 份。 |
| 领取后的标题重载 | 四台设备均为空闲，逐台再次领取均被拒绝，库存保持。 |
| 整个进程冷启动 | 新进程从磁盘加载夏 1，仅重跑最后的重复领取检查。四台均拒绝再次领取。 |

首轮报告为 `Completed=true`、`Stage=3`、`Passed` 六项、`Failure=null`。原生日志独立确认四次加载、三次保存和六项实际执行。冷启动日志确认一次加载、零次保存和最后一项实际执行。冷启动报告中的前五项来自磁盘检查点。两次 SMAPI 日志均无 `WARN` 或 `ERROR`。

只读检查最终 XML，确认第 1 年夏 1，背包确有豆腐 6 份和酱油 4 份。四台设备的实例 ID 各异，修订号依次为 `4/4/2/2`，批次均为空，设备状态原文与磁盘检查点一致。

## 停止与覆盖范围

两次运行均在终态报告落盘后关闭。启动方式未提供可用的主窗口句柄，通过进程停止结束两次测试。停止后核对游戏进程为零，夹具配置恢复为原禁用字节。冷启动前后专用档的 4 个文件哈希相同，测试前后 39 个既有存档文件哈希相同。原报告、日志、基线和审计摘要保存在 `.local/p1-current-persistence`。

本轮覆盖独立农场中的原生存读档和单人重复领取。完整普通游玩链仍需在自然营业时间步行采购，经正常加工工时完成两条配方，再通过原版厨房和成品用途收尾。多人争用另按 P1-NET-03/04 验收。当前进度见 [P1 单人状态](../P1_SINGLEPLAYER_STATUS.md)。
