# 乡野时令 · Xiangye Shiling

面向《星露谷物语》的中国时令采集与农家加工模组。

出门采野菜，在农场种黄豆和白菜，回家用少量设备加工，再做成能吃、能送、能出售的中式食物。

> 当前状态：**P1 单人机器原型开发中，联机加工/放置禁用**。设计基线为 **0.4 收敛版**；工程版本为 `0.1.0-alpha.2`。已接入豆坊、发酵缸菜单与实际背包事务、原型商店/图纸/菜谱，以及待双客户端实测的只读握手/拒绝桥；完整 P1 验收仍未完成，不是正式发行版。

## 开发方向

首个验证基线为 Windows x64 /《星露谷物语》1.6.15 / SMAPI 4.4.0 / Content Patcher 2.9.0。内容数据优先使用 Content Patcher；豆坊和发酵缸共享的配方选择、批量投料与状态管理作为小型 SMAPI 模块的验证重点。仅声明实际完成的检查，不将编译成功视为游戏兼容验收。

开发按“公共机制验证 → 完整内容 → 平衡与验收”推进。被设计文档排除的内容不作为后续版本承诺。
