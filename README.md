# 乡野时令 · Xiangye Shiling

面向《星露谷物语》的中国时令采集与农家加工模组。

出门采野菜，在农场种黄豆和白菜，回家用少量设备加工，再做成能吃、能送、能出售的中式食物。

> 当前状态：方案设计。设计基线为 **0.4 收敛版**，不是可安装的模组版本。仓库目前只有设计与开发计划，尚无实现代码、游戏内验证或可下载发行包。

## 本期范围

| 类别 | 内容 |
|---|---|
| 春季采集物 · 4 种 | 竹笋、野葱、香椿、艾草 |
| 种植作物 · 2 种 | 黄豆、大白菜 |
| 商店食材 · 2 种 | 猪肉、蚕豆 |
| 加工品 · 15 种 | 6 种基础豆制品、3 种豆制熟食、4 种发酵品、2 种烟熏品 |
| 配套料理 · 13 道 | 接通上述原料与加工品的实际用途 |
| 新设备 · 2 种 | 豆坊、发酵缸；复用原版厨房与熏鱼机 |

合计 36 种原料、加工品与料理物品；另有 2 种种子、2 种设备。厨房共新增 16 个食品配方（13 道料理及 3 种豆制熟食）。

同一批原料选定配方后，内部完成浸泡、煮浆、凝固、压制或发酵等工序。每个保留物品都有来源与用途；不增加单用途工具、腐败系统、专用工艺耗材或复杂科技面板。

## 开发方向

暂以桌面版《星露谷物语》1.6 为目标。内容数据优先使用 Content Patcher；豆坊和发酵缸共享的配方选择、批量投料与状态管理作为小型 SMAPI 模块的验证重点。确切版本、操作系统和兼容范围将在原型阶段记录。

开发按“公共机制验证 → 完整内容 → 平衡与验收”推进。被设计文档排除的内容不作为后续版本承诺。

本项目是非官方玩家模组。
